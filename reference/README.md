# Sources de référence

Ces instantanés retracent les paramètres et l’intégration Aurora d’origine. Ils ne sont pas des entrées de build. Les fichiers `.txt` conservent les anciens scripts et adaptateurs sans les indexer comme sources actives. Le XCI est une référence de configuration. Les scripts actifs sous `scripts/` génèrent deux nouveaux cœurs duplex.

Le rapport et la consigne sont conservés tels que fournis ; les figures et les fichiers auxiliaires qu’ils citent n’étaient pas tous joints. Le README du nouveau projet et les tests fournis décrivent ce qui est effectivement livré.

`Obsidian.net` est l'export KiCad de la carte Obsidian révision 1.1.0, utilisé
pour vérifier les broches FPGA, les connecteurs et les points de test. Il est
conservé sans modification et n'est pas une entrée de build.
